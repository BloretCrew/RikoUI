Riko UI

源自《络的世界》的温馨手绘风 UI 框架。米色纸张、浅棕描边、冰蓝点缀与暖橙五角星——把治愈的童话感带进任何项目。

开始使用 浏览组件

特点 Features

零依赖

纯 CSS + 原生 JS，一个样式表加一个脚本即可，任何框架都能用。

深浅色

按系统、按时间、浅色、深色四种模式，所有组件自动适配。

对 AI 友好

llms.txt、组件清单与 riko-ui check 检查器，AI 一次写对。

无障碍

WCAG AA 对比度、完整键盘操作、焦点可见、减少动效。

手绘童话风

米色纸张、缝线、胶带、波浪线与暖橙星星。

全球可访问

自托管字体与 npm 镜像，中国大陆同样顺畅。

安装 Install

1

用 npm 安装

npm i @bloret-crew/riko-ui lucide
npm i @bloret-crew/riko-ui-fonts   # 可选：自托管字体
import '@bloret-crew/riko-ui-fonts/riko-fonts.css';
import '@bloret-crew/riko-ui/css';
import Riko from '@bloret-crew/riko-ui';   // 自动初始化，并挂到 window.Riko
2

或者直接用 CDN

中国大陆可把 cdn.jsdelivr.net 换成 npmmirror 镜像，或把 dist/ 目录自托管到任意服务器。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <script src="https://cdn.jsdelivr.net/npm/@bloret-crew/riko-ui@0/dist/riko-theme-init.js"></script>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@bloret-crew/riko-ui@0/dist/riko-ui.min.css">
</head>
<body class="riko-plaid">
  <div class="riko-glow" aria-hidden="true"></div>
  <main class="riko-container riko-section">
    <h1 class="riko-h1">你好，Riko UI <span class="riko-star" aria-hidden="true"></span></h1>
    <button type="button" class="riko-btn riko-btn--primary">开始阅读</button>
  </main>
  <script src="https://unpkg.com/lucide@latest"></script>
  <script src="https://cdn.jsdelivr.net/npm/@bloret-crew/riko-ui@0/dist/riko-ui.min.js"></script>
</body>
</html>
3

让 AI 来写

把下面这段放进项目的 CLAUDE.md / AGENTS.md，AI 就会读取随包附带的 llms.txt，并在交付前自检。

本项目使用 Riko UI。写界面前先读 node_modules/@bloret-crew/riko-ui/llms.txt，
交付前运行 npx riko-ui check <改动的文件>，0 错误才算完成。
